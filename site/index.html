Rust crypto benchmarks

How fast Rust crypto libraries seal and open 1280-byte ChaCha20-Poly1305 messages, the hot path of a WireGuard tunnel. Every implementation is checked against test vectors before it is timed. Anyone can add results from their machine: firezone/rust-crypto-benchmarks.

Each implementation is measured in several interleaved rounds, pinned to the fastest core; the median is the median of the round medians and the spread is half the range of the round medians, relative to the median. Throughput is the message rate at the median, in gigabits per second. Each operation reads the message from one buffer and writes the result to another; libraries with an in-place API copy it first. Cycles per byte come from the CPU's own cycle counter where a user program can read it (Linux, Apple silicon), so they compare across machines where time does not.
